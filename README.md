## 어려웠던 점 3가지와 해결
1. 보너스의 로딩 스켈레톤을 위해 index.html에 div를 3개 추가하니, css의 카드 등장 애니메이션의 순서가 어긋나 이상하게 등장하는 상황이 발생. --> 교재를 참고해 자식 요소의 개수를 고려해 css에서 자식의 번호를 변경 후 해결

2. 이미 index.html에 body 태그가 있는데 main 안에 body class="detail-page"를 넣어 
error가 발생. --> 교재를 참고해 body가 2번 쓰이면 안 된다는 것을 확인 후 해결

3. 로딩 스켈레톤을 적용시킨 화면을 보기 위해 detail.html에 body class="is-loading"을 넣고 실행하니 적용이 안됨 --> index.html에도 body class="is-loading"을 넣으니 해결
